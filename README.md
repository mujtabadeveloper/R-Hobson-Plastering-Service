# R Hobson Plastering Service

Static HTML, CSS and JavaScript website. Includes the latest enhanced project photograph.

## GitHub and Vercel
1. Extract this ZIP.
2. Upload index.html, assets, vercel.json and the other included files to the root of a GitHub repository.
3. Import the repository in Vercel. Select Other as the framework. Leave the build command empty and use the repository root as the output directory.

Open index.html locally to preview, or run python -m http.server 8000.

The quote form opens WhatsApp with the entered details for the visitor to review and send. It does not store enquiries on a server.
